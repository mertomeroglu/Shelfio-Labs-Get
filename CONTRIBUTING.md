# Contributing

This repository is maintained as a public portfolio version of the GetShelfio service site and portal monorepo.

Before opening a pull request:

- Keep changes scoped to GetShelfio only.
- Do not commit `.env` files, logs, database dumps, uploads, build output, or private deployment files.
- Do not add real credentials, license keys, SMTP passwords, database URLs, private IP addresses, or local machine paths.
- Keep implemented and planned features clearly separated in documentation.
- Run the relevant lint, typecheck, or build command before submitting changes.

Public visibility does not grant permission to reuse private branding, deployment configuration, customer data, or proprietary business logic outside the license terms in this repository.
