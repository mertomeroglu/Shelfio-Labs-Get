# Security Policy

Please do not disclose security vulnerabilities through public GitHub issues, pull requests, or discussions.

If you believe you found a vulnerability, report it privately to:

- `support@example.com` until a project-specific security contact is configured

Include a concise description, reproduction steps, affected files or endpoints, and any logs that do not contain secrets.

Do not include real credentials, API keys, database URLs, customer data, license keys, private server names, or access tokens in reports.

This repository is intended for public portfolio review, but public visibility does not make it production-ready without environment-specific hardening, secret rotation, monitoring, backups, and deployment review.
